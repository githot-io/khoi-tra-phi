# Khỏi trả phí

Danh sách phần mềm mã nguồn mở, miễn phí trên GitHub mà [GitHot](https://www.githot.io.vn) đã review và viết **hướng dẫn cài đặt từng bước bằng tiếng Việt**, dành cho người không rành kỹ thuật. Mỗi hướng dẫn được đối chiếu với tài liệu chính thức của dự án và có video review ngắn trên kênh [AI Mỗi Ngày](https://www.tiktok.com/@dailytech_ai).

Không thấy phần mềm bạn cần? Tìm trên [githot.io.vn](https://www.githot.io.vn), hoặc [mở một issue](../../issues/new) để đề xuất.
